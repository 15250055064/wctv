# WCcanvastv 本地工具清单（实测版）

所有工具都在你的 Mac 上运行：**不花钱，也不消耗 ChatGPT 额度**（「图片拆解」选 ChatGPT 重绘背景时除外）。

- 模型和程序都是**第一次用到时才下载**，不打进安装包，下载后离线可用。存放在 `~/Library/Application Support/WCcanvastv/engines/`（`tools/` 放程序，`vision/` 放模型）。
- 用的时候才加载，用完就释放。
- 下面的数字是在 **M1 Max（64 GB 内存）** 上实测的。视频类按「10 秒、1080p、30 帧」换算。
- 「内存」一栏：本机程序（放大、补帧、矢量、降噪、人声分离）是实测的峰值；在应用里用 GPU 跑的模型（抠图、橡皮擦、文字识别、转文字、虚化）是按模型大小估的。
- 没用过的工具不会下载。全部用过一遍，一共下载约 **1.4 GB**。

## 二、和原计划不一样的地方

| 原计划 | 实际 | 原因 |
|---|---|---|
| 抠图用 BiRefNet（约 200 MB） | 换成 **IS-Net**（176 MB） | BiRefNet 有一层运算超出了苹果 GPU 的限制（每个着色器最多 10 个存储缓冲，它要 11 个），在 GPU 上跑不了；在 CPU 上跑要占 **8.5 GB** 内存。IS-Net 在 GPU 上 0.3 秒一张，抠出来的效果加了边缘处理后很干净。 |
| 转文字用 whisper.cpp | 换成 **Whisper 的 ONNX 版**，在应用里用 GPU 跑 | whisper.cpp 没有现成的 Mac 程序，要在用户电脑上编译。ONNX 版不用编译，速度也很快（30 秒音频 2.6 秒）。 |
| Demucs 约 80 MB | 实际 **290 MB** | 能直接用的 ONNX 版把频谱转换也打包进了模型；另外需要 44 MB 的 ONNX Runtime 运行库（只下载 Mac 版那部分）。 |
| 补帧：RIFE 约 20 MB | 实际下载 **18 MB**，占用 35 MB | RIFE 官方的 Mac 压缩包有 436 MB（装着所有模型版本），应用用分段下载**只取出程序和 v4.6 一个模型**。 |
| 图片压缩用 sharp | 用应用自带的浏览器引擎 | 不用额外装任何东西，WebP / JPEG / PNG 都能转。 |
| B 视频高清放大（原计划不做） | 做了，**固定 2 倍、最高 4K** | 照片模型 realesrgan-x4plus 一帧 720p 要 10 秒，10 秒视频要近 1 小时；专门的视频模型 0.4–0.6 秒一帧。 |
| 视频去背景输出透明视频 | 透明视频默认输出 **WebM**，另可选 ProRes 4444、绿幕、白底 | ProRes 4444 一段 4 秒就 200 MB，而且应用里预览不了；WebM 小得多，在应用和网页里都能直接播放。要导进 Final Cut / Premiere 时选 ProRes。 |

## 三、关于「不臃肿」

- 安装包里**不装 Python**，也没有任何模型。
- 本机程序都是现成的 Apple 芯片版（ncnn、Rust、ONNX Runtime）。
- 应用里的模型都和已有的深度提取共用同一个运行环境（ONNX Runtime Web），没有再装第二个。
- 所有工具都是用到时才加载，应用启动时加载的代码基本没变（约 0.66 MB）。
