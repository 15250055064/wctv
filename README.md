# WCcanvastv

一个本地运行的 AI 创作画布（Mac 应用）。在无限画布上用节点组织文本、图片和视频：文本由 **ChatGPT** 或 **Claude Code** 生成，图片由 **ChatGPT** 生成，直接调用你电脑上已登录的 AI 应用，**不需要 API Key**。上传的视频、图片和生成结果都按项目保存在本地留档。

## 系统要求

- macOS，**Apple 芯片**（M1 / M2 / M3 / M4 …）。暂不支持英特尔芯片的 Mac。
- 至少一个 AI 应用并已登录：
  - **ChatGPT**（必需，用于文本和图片）：需要 ChatGPT Plus 或更高的订阅
  - **Claude Code**（可选，用于文本和视频玩法）：需要 Claude Pro / Max 订阅
- 生成使用的是**你自己账号的额度**。

> **让 AI 帮你部署**：把 [docs/DEPLOY.md](docs/DEPLOY.md) 交给你的 AI 编程助手（Claude Code、ChatGPT 等），说「按 docs/DEPLOY.md 在这台 Mac 上部署 WCcanvastv」。里面有安装包、本地引擎和模型的下载地址、国内镜像、存放路径和每一步的检查方法。安装包本身不含任何大模型。

## 第一步：安装 WCcanvastv

1. 下载 **[WCcanvastv-mac-arm64.zip](../../releases/latest/download/WCcanvastv-mac-arm64.zip)**，双击解压。
2. 把 **WCcanvastv.app** 拖进「应用程序」文件夹。
3. **第一次打开**：应用没有经过苹果签名，直接双击会提示"无法验证开发者"。任选一种方式放行：
   - 在「应用程序」里**右键 WCcanvastv → 打开**，在弹窗里再点「打开」；或者
   - 打开「系统设置 → 隐私与安全性」，在页面底部找到 WCcanvastv，点「仍要打开」；或者
   - 打开「终端」，运行：

     ```bash
     xattr -dr com.apple.quarantine /Applications/WCcanvastv.app
     ```

   放行一次即可，以后正常双击打开。

打开后，右上角会显示 ChatGPT 和 Claude 的状态：**绿点**表示已就绪，**黄点**表示未安装或未登录。

## 第二步：配置 ChatGPT

WCcanvastv 通过 OpenAI 的 **Codex 命令行**调用 ChatGPT，用的是你的 ChatGPT 账号登录，不需要 API Key。任选一种安装方式：

**方式 A：ChatGPT 桌面应用（自带 Codex）**

1. 从 [chatgpt.com/download](https://chatgpt.com/download) 下载并安装最新版 ChatGPT 桌面应用，放进「应用程序」。
2. 打开并登录你的 ChatGPT 账号，再在应用里打开 Codex 并完成登录。

**方式 B：单独安装 Codex 命令行**

需要先安装 [Node.js](https://nodejs.org)（推荐 LTS 版），然后在「终端」运行：

```bash
npm install -g @openai/codex
```

```bash
codex login
```

按提示选择「Sign in with ChatGPT」，在浏览器里完成登录。

配置好后重新打开 WCcanvastv，右上角 ChatGPT 变为绿点即可。

## 第三步：配置 Claude Code（可选）

1. 在「终端」运行官方安装命令：

   ```bash
   curl -fsSL https://claude.ai/install.sh | bash
   ```

   （也可以先装 [Node.js](https://nodejs.org) 再运行 `npm install -g @anthropic-ai/claude-code`。）
2. 运行下面的命令，按提示在浏览器里登录你的 Claude 账号：

   ```bash
   claude auth login
   ```

3. 重新打开 WCcanvastv，右上角 Claude 变为绿点即可。

> Claude 只能生成文本，不能生成图片。图片节点请选择 ChatGPT。

## 使用说明

### 项目

- 左上角是**项目名**，直接修改后回车即可重命名（项目文件夹会同步改名）。
- 点项目名旁的 **▾** 可以新建项目、打开其他项目，或在访达中显示项目文件夹（留档文件都在里面）。也可以用菜单「文件 → 新建项目（⌘N）/ 打开项目（⌘O）」。
- 每个项目是一个文件夹：`~/Movies/WCcanvastv/项目名/`，里面有画布存档和这个项目的所有素材，按日期分子文件夹。

### 生成

1. **双击画布**或按 **Tab** 新建节点：文本、图片、脚本等。
2. 选中节点，在下方面板输入提示词，选择 **ChatGPT** 或 **Claude Code**，点 ↑ 或按 **⌘↵** 生成。
3. 从一个节点右侧的 **＋** 拖出连线，连到另一个节点：上游的文本会作为上下文，上游的图片会作为参考图。
4. 文本约十几秒，图片约 1 分钟，节点上会显示进度。

### 连线会带来什么

连到一个生成节点（文本 / 脚本 / 图片）上的内容，都会进入这次发给 AI 的内容：

| 连进来的 | 效果 |
| --- | --- |
| 文本、脚本 | 作为参考文本 / 分镜一起发送 |
| 图片 | 作为参考图发送 |
| 视频 | 自动截取一帧画面，作为参考图发送 |
| 风格 | 追加画面风格要求 |
| 视频玩法 | 按这个玩法的方法写（分镜结构、画面规则、生图与视频提示词写法） |
| 特效 / 运镜 | 脚本和文本按这种运镜设计镜头；图片把它的瞬间感体现在构图里 |
| 角色（或提示词里 @角色名） | 追加角色设定，并附上角色图（如已生成） |
| 我的偏好 | 每次都放在最前面（可分别对 ChatGPT / Claude 开关） |
| 音频 | 视频玩法节点会把它作为配音或配乐素材；其他节点不使用 |
| 参考节点 | 不参与生成 |

点提示词面板的「**发送内容**」可以在生成前看到完整的发送内容和未使用的连线；生成后点节点工具栏的文件图标，可以查看那一次实际发送的内容。

文本、脚本、视频提示词和「GPT/Claude 写口播」的结果下方都有「**生成思路**」：AI 逐条说明每个连入的素材（按名称）读到了什么、用在了哪里，没用上的也会说明原因，以及做了哪些取舍。连入的图片按顺序编号为 图片1、图片2…，提示词里的 @图片N 都能对上。

文本、脚本、视频提示词和配音节点可以拖动四角调整大小；选中脚本或视频提示词节点后可以直接修改内容，也可以复制粘贴。

### 时长

视频提示词、音乐和视频玩法的「时长」都可以选：**按文案**（默认，按提示词里写的时长来；没写就由 AI 按内容决定）、常用的 10 / 15 / 30 / 60 秒等，或「**自定义**」输入任意秒数。视频提示词超过 15 秒时会拆成多条首尾相接的提示词。

### 视频提示词（Seedance 2.0）

文本节点把「类型」切到「视频提示词」后，按 [Seedance 2.0 提示词方法](https://github.com/Emily2040/seedance-2.0)（MIT）写视频生成提示词：先做导演解读（剧情 / 观察 / 功能展示），再写成一个镜头一个可见动作、一个主运镜、物理光源、声音意图和连续性锁定的提示词。连入分镜脚本时逐镜一条；连入参考图时自动写成图生视频并标明 @图片N 的作用（首帧、身份、产品、风格）。可选时长、画幅和中文 / 英文。

### 视频玩法

「视频玩法」节点**直接做出成片**：从底部「素材库 → 视频玩法库」（和风格库、特效库在一起）选一种玩法添加到画布，或新建「视频玩法」节点后再选（也可以不选，让 AI 自由创作）。节点里依次是：**素材**（连线进来的节点，或点「添加素材」上传、直接把图片 / 视频 / 音频拖进来）、**想做什么视频**、制作者（Claude Code / ChatGPT）、画幅、时长，最后点「**开始制作**」。AI 会在项目里开一个制作文件夹，读这个玩法的完整方法文档，用 [HyperFrames](https://github.com/heygen-com/hyperframes)（HeyGen 开源，Apache-2.0）以 HTML + GSAP 写出动画，自己检查画面，再用本机的 Chrome 和 FFmpeg 渲染成 MP4，放回节点上，并附上「制作说明」（创意思路、分镜表、改哪里）。一部 10–30 秒的片子通常需要 5–20 分钟。

- 连进玩法节点的文本、脚本、图片、视频和音频，都会作为素材放进制作文件夹交给 AI。
- 需要时 AI 会自己调用本地工具：ChatGPT 生成插画、Qwen3-TTS 配音、ACE-Step 配乐（已安装的才会用）。
- 做完后点「**在 Studio 中编辑**」，在 HyperFrames Studio 里直接改文字、画面和时间线，改完点「**渲染为新版本**」；也可以把「方式」切到「改上一版」，用一句话告诉 AI 哪里要改。
- 「打开文件夹」可以看到全部源文件，位置是 `项目名/制作/日期-时间-标题/`。

视频玩法第一次使用前，需要在右上角「**本地引擎**」里安装「HyperFrames 视频制作」（约 500 MB：Node.js、HyperFrames、渲染用的 Chrome）。

6 种玩法，打开玩法库可以看到效果预览、功能简介和来源仓库。玩法节点也可以连到文本、脚本、图片或视频提示词节点上，让 ChatGPT 和 Claude 按它的方法来写：

| 玩法 | 来源（MIT） | 适合 |
| --- | --- | --- |
| Q版蜡笔手绘 | [kaomei/hand-drawn-video-prompts](https://github.com/kaomei/hand-drawn-video-prompts) | 科技、财经、知识类竖屏口播 |
| 复古纸质拼贴 | [Alisa0808/vox-director](https://github.com/Alisa0808/vox-director) | 历史、人物、品牌故事、观点讲解 |
| 手绘口播（边画边讲） | [threerocks/sweety-handdraw-video](https://github.com/threerocks/sweety-handdraw-video) | 知识讲解、寓言、产品原理 |
| 自动选题出片（白板 / 调查） | [trustfuture/simon-skills](https://github.com/trustfuture/simon-skills) | 科技商业解读、消费调查 |
| 艺术动画 | [alchaincyf/huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion) | 艺术风格短片、解说动画 |
| 机械交互图解 | [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy) | 技术原理、产品机制 |

这些仓库原本是给 AI 编程助手用的完整出片工具。制作成片时，AI 会读到它们的完整方法文档（随应用附带，含各自的 LICENSE），但其中的付费云服务（火山引擎、Atlas Cloud 等）一律换成本机工具，渲染统一用 HyperFrames。

### 配音（文字转人声）

音频节点把「类型」切到「配音」，把文字读成人声：可以直接朗读输入或连入的文本 / 脚本，也可以把「文案」选成「AI 写口播」，先由节点选的 ChatGPT 或 Claude 改写成口播稿再朗读。9 种音色（温柔女声、明亮女声、低沉男声、京味、川味、英文、日语、韩语等）和多种语气（温柔、激昂、悬疑、新闻播报、讲故事…）。

使用本地开源模型 [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)（Apache-2.0），通过 [mlx-audio](https://github.com/Blaizzy/mlx-audio)（MIT）在 Apple 芯片上运行；没安装时可以选「系统语音」。

**转旁白 / 转音乐**：选中文本节点，顶部工具栏点「转旁白」或「转音乐」，会在右边新建一个连好的配音 / 配乐节点并选中它。先选好音色（男声 / 女声）、语气，也可以在输入框里写朗读要求（如「语速稍慢，带点笑意」——连了文本时这里是要求，不会被读出来），再点 ↑ 生成。

**声音克隆**：音频节点的「类型」选「克隆声音」，把一段录音（音频节点，3–15 秒清晰人声最好）连进来，就会用这个声音朗读。录音会先用 Whisper 自动识别文字，再交给 Qwen3-TTS Base 模型克隆；首次使用会下载约 4 GB 模型。请只克隆你本人或已获得授权的声音。

### 留档

- 把视频、图片、音频**拖进画布**，或在空的视频节点里点「上传视频」，文件会存进当前项目的文件夹。
- 在画布上 **⌘V 粘贴链接**：图片、视频、音频的直链直接下载；抖音、B 站、小红书、YouTube 等页面链接用 [yt-dlp](https://github.com/yt-dlp/yt-dlp)（Unlicense，首次使用自动下载约 35 MB）下载视频。要登录才能看的视频（抖音常见）下载不了，可以先在 App 里保存再拖进来。
- **⌘V 粘贴文字**直接变成文本节点。
- 生成的图片也会自动存进项目文件夹。
- 在图片 / 视频节点或素材上**右键 → 在访达中显示**，可以直接找到文件。
- 左下角「资产管理 → 本地留档」可以浏览当前项目或全部留档，并拖回画布。

### 3D 导演台

添加「导演台」节点并双击打开：

- **搭场景**：添加人物（可调关节的木偶人）、机位和道具（方块、墙面、桌椅、门、树、汽车等），用移动 / 旋转 / 缩放工具（W / E / R）摆放，右侧面板精确修改位置、旋转、缩放和颜色。
- **姿势**：站立、行走、奔跑、坐下、蹲下、挥手、指向前方、叉腰、思考、举双手、拥抱、跳跃等预设，并可逐个关节微调。
- **机位**：在「导演视角」和「机位视角」之间切换，选择画幅（16:9、9:16、2.39:1 等）和视野；「机位对齐视角」把机位移到当前导演视角；「注视目标」让镜头始终对准某个人物或道具。
- **关键帧动画**：底部时间轴上拖动播放头到某个时间，选中物体点「添加关键帧」（K），换个时间再移动它、改姿势或改视野，就会自动记下新的关键帧。关键帧可以拖动改时间，过渡可选「匀速 / 缓入缓出 / 定格」；勾选「自动记录」后改动任何物体都会打关键帧。空格播放，← / → 逐帧。
- **AI 生成**：底部输入框有三种模式，可先把参考图连到导演台节点上：
  - **搭场景**：描述场景，自动摆好人物、道具和机位；
  - **生成动画**：描述动作和运镜（如「人物走到长椅前坐下，镜头跟随并缓慢推近」），自动为人物和机位生成关键帧，生成后仍可逐帧修改；
  - **生成模型**：描述一个物体（如「复古红色自行车」），用几何体拼出模型放进场景。
- **动作捕捉**：在人物的「姿势与动作」里，从画布上的视频或本地视频识别人物动作（Google MediaPipe，本机运行），动作从时间轴当前位置开始播放，可以和位置关键帧一起用。适合单人、全身、清晰的画面；动作保存在动作库里，所有项目都能选用。
- **截图 / 导出视频**：按当前机位渲染当前画面为图片，或把整段动画渲染成 1080p 视频，放到画布上。

### 文字生成音乐

在音频节点里描述想要的音乐（风格、情绪、乐器、节奏），选择引擎、人声和时长，点生成：

- **ACE-Step 歌曲**（默认）：ChatGPT 或 Claude 写歌词（带主歌 / 副歌等段落）和英文风格描述，本地开源模型 [ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5)（MIT）生成带人声或纯音乐的完整歌曲，支持中文歌词。30 秒的歌在 M1 Max 上约 1 分钟（首次需要启动引擎）。
- **合成小样**：AI 写出乐谱，WCcanvastv 在本地合成为电子配乐小样，没有人声，不需要安装引擎。

### 本地引擎

右上角「**本地引擎**」打开引擎管理，一键安装 Qwen3-TTS 配音（约 4 GB）、ACE-Step 音乐（约 15 GB）和 HyperFrames 视频制作（约 500 MB）。安装会下载运行环境和模型，文件放在 `~/Library/Application Support/WCcanvastv/engines`，可以随时卸载；无法访问 HuggingFace、npm 或 nodejs.org 时自动改用国内镜像。它们都只在本机运行，不需要账号或 API Key。建议 16 GB 以上内存。

### 视频工具

选中一个视频节点，顶部工具栏有四个按钮：

- **逐帧拉片**：自动识别镜头切换并截取每个镜头的关键帧，交给 ChatGPT / Claude 逐镜头分析分镜、运镜、光影色调（可选声音音乐推测），生成一个分镜脚本节点。
- **画面裁切**：拖动框选区域，可选 16:9、9:16、1:1 等比例，导出新视频。
- **音视频分离**：拆成无声视频和音频两个文件。
- **深度提取**：用 [Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2)（Apache-2.0）在本机逐帧估计画面深度，生成黑白深度视频（越近越白），可选 480P / 720P，可用作 ControlNet、合成或重打光的深度参考。处理时间约为视频时长的 1–3 倍。模型（约 47 MB）不随应用附带，第一次使用时自动下载（连不上 HuggingFace 时改用国内镜像），之后离线可用。

所有结果都会存进当前项目的文件夹。视频处理使用内置的 [FFmpeg](https://ffmpeg.org)（许可证见应用内 `bin/ffmpeg.LICENSE`）。

### 本地工具（免费、离线）

选中图片、音频或视频节点，上方会多出一排**工具**（鼠标停在按钮上会显示说明），结果会作为新节点连在右边，文件存进项目文件夹。这些工具都在你的 Mac 上运行，不花钱、不消耗 ChatGPT 额度；第一次用某个工具时会自动下载它需要的程序或模型（连不上外网时自动改用国内镜像），之后离线可用。

- **图片**：一键抠图、图片拆解（拆成背景 + 主体图层，选中分组可「导出 PSD」）、魔法橡皮擦（涂抹要去掉的东西）、高清放大（2 / 4 倍）、识别文字、提取配色、压缩 / 转格式（WebP、JPEG、PNG）
- **音频**：转文字（带时间）、人声伴奏分离、降噪
- **视频**：剪辑修剪（剪头尾、保留多段、变速）、补帧变流畅（帧率翻倍）、视频高清（2 倍，最高 4K）、智能去字幕（自动找出字幕并抹掉）、视频去背景（透明 WebM / ProRes、绿幕、白底）、视频去水印（框出位置），以及上面三个音频工具。自动分镜（按镜头拆成片段）在「逐帧拉片」里

每个工具用的开源项目、下载大小、内存和实测速度见 [docs/LOCAL_TOOLS.md](docs/LOCAL_TOOLS.md)。全部用过一遍约下载 1.4 GB。

## 常见问题

**打开时提示"已损坏，无法打开"或"无法验证开发者"**
按[第一步](#第一步安装-libcanvas)第 3 点放行即可。

**右上角显示"ChatGPT 未安装"或"未登录"**
确认已按[第二步](#第二步配置-chatgpt)安装并登录，然后完全退出 WCcanvastv（⌘Q）再重新打开。

**右上角显示"Claude 未登录"**
在终端运行 `claude auth login` 重新登录，然后重新打开 WCcanvastv。

**在 ChatGPT 应用里看不到生成记录**
这是正常的：WCcanvastv 在后台调用，不会保存会话，所以不会出现在聊天记录里。生成仍然使用你的账号和额度。

**ChatGPT 的「记忆」会自动生效吗？**
不会。命令行读不到 ChatGPT 的记忆和自定义指令，请把需要的内容复制到「我的偏好」。

**端口 5174 被占用**
WCcanvastv 在本机 5174 端口运行内置服务（只接受本机访问）。如果提示端口被占用，请关闭占用该端口的程序后重试。

**文件存在哪里？**
`~/Movies/WCcanvastv/`（即「影片 → WCcanvastv」），每个项目一个文件夹。角色库、工具箱和偏好保存在 `~/Movies/WCcanvastv/.libcanvas/`（隐藏文件夹）。

## 从源码构建

需要 [Node.js](https://nodejs.org) 22 或更高版本。

```bash
git clone <本仓库地址>
cd <仓库目录>
npm install
npm run app
```

打包好的应用在 `release/WCcanvastv-darwin-arm64/WCcanvastv.app`。

开发时也可以不打包，直接运行 `npm start`，然后在浏览器打开 http://localhost:5174 。

### 结构

- `server/index.mjs`：本地服务（只监听 127.0.0.1，拒绝其他网站的请求），负责调用 ChatGPT / Claude Code、读写项目和留档文件
- `electron/`：Mac 应用外壳（窗口、菜单、打包脚本、图标）
- `src/canvas/`：画布前端（React + React Flow）
