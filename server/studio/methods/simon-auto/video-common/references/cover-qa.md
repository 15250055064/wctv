# AI 封面：比例与验收（只讲机制，画面风格在各账号）

- 默认两张独立资产：**3:4 竖版**（视频号竖版、小红书）与 **4:3 横版**（公众号、B 站）。视频是 16:9 不代表封面也是；不擅自扩成 9:16 / 16:9 四件套，用户指定比例从其要求。
- 两种比例各自构图，横版不是竖版裁切；每次生成只出一个明确比例。用内置 imagegen 出完整封面（文字与场景一体），不拿视频截图、HTML 排版图或纯提示词冒充。调用前读当前 imagegen 说明，不照搬旧脚本的 API。
- 提示词写清：主体、标题原文、视觉重心、安全区、禁造事实。真实商品、单据、证照、金额读数不能 AI 伪造；概念物件标"AI 概念封面"。
- 生成后实测宽高：3:4 要 `宽×4 = 高×3`，4:3 要 `宽×3 = 高×4`；提示词里的尺寸不算证据。1086×1448 / 1448×1086 也是准确比例，不必为凑 1080 重画。
- 目视检查：中文逐字、边缘切字、主体数量、品牌标位置；缩到 240~320px 看主标题和关键反差还能不能读。OCR 只辅助，错字以目视为准。文字不准时用图像编辑修，拆短行比挤一行可靠。
- 保留生成原图，交付另存到本期正式目录；最终链接指向实际交付文件，文案与封面同版本。
