# 事实核查与来源台账

## 查
- 官方原件优先并读到全文：官网、发布会、财报、监管文件、史书原文/权威校注。二手站与聚合站的数字只当线索，回原件核。
- 官网抓取被拦（403、验证页）时，换带浏览器 UA 的 curl，或用浏览器工具打开读正文；再不行用 Wikipedia、官方开发者文档交叉。
- 关键转折至少两源交叉；只有单一来源时写明证据范围。

## 记
- 每个用到的数字、日期、价格、引语都进本期来源文件（白板讲解视频是期目录 `README.md`「资料来源」，调查长片是素材台账）：来源链接、篇章/页码或时间码、支持哪一句、核对日期。
- 口径单列一节（"240 倍 = 6000 万 / 25 万"），旁白、字幕、封面、文案里的数字都从这一节取，改一处全改。

## 写
- 估算值在旁白和文案里都标"据报道 / 估算 / 舆论认为"；公开报道不是作者亲历，未查明原因不写成实锤。
- 事实核对日期随材料走，收录或改写日期不冒充重新核查；引入新事实或时效性规则时重新核。
- 引文只有真实出处才加引号；传说、争议说法在口播里说明；不编造心理活动、对白、聊天记录、单据。
- AI 生成的物件、场景、复原相貌标"概念示意 / 艺术化复原"，不当证据用。
