# 成片机器验收与交付边界

## 机器检查（必做）
```bash
ffprobe -v error -show_entries format=duration:stream=index,codec_type,codec_name,width,height,r_frame_rate,duration -of json final.mp4
ffmpeg -v error -i final.mp4 -f null -
```
- 尺寸、fps、总时长、音轨存在且非静音；视频与音频结束对齐（允许一帧量化误差）。
- 字幕区间有序、不重叠，每句确认正文都有音频和画面；尾句说完再压黑。
- 黑帧检测后人工判断，深色品牌底不等于黑帧；无黑帧也不证明视频层正常。
- 时长以 `ffprobe` 为准写进索引/README，不用接口估时。

## 目视抽帧（必做）
- 首、中、尾各一帧，外加每处结构变化（章节、证据入场/退场、MG 初/中/终、片尾）。
- 看：字幕在安全区、品牌标位置、无越界遮挡、贴纸/素材边缘正常。
- 运动镜头要连续播放或看相邻帧，单帧不能证明平稳；未逐秒听审就如实写"未完成"。

## 交付边界
- 只宣称实际完成的检查，QA 报告分开写机器检查、目视检查、未完成项。
- 路径指向可播放的新成片；存在旧 MP4 不代表新版本已合成，"final / v3 / 完整版"文件名不代表状态，以项目入口指定的有效版本为准。
- 已制作 ≠ 已发布。制作授权不含公开发布，用户验收材料不等于已上线。
- 改稿后旧导出冻结，需重出片并更新本期入口；不覆盖用户源素材和已交付成片。
