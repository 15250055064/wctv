# 调查叙事视频

目标：故事由具体画面推进，机制由 MG 解释，结论有出处，品牌与账号配置保持一致。本包的 **30 秒视觉升级 v2 样片**保留为拼贴质感参考；长片同时遵循《零食称重》制作中确认的真实素材、动态叙事与发布要求。样片不代表长片素材已经够用。先看相应参考成品，再设计；参考的认可范围见各文件，不把一次认可扩大到全部后续版本。

## 先确定本轮范围

- 用户要求学习对标的“画面／质感”时，围绕构图、素材合成、景深、边缘、字体、光影与动态制作展开；不要把交付转成选题、文案或叙事结构优化。
- 延续已有选题、旁白、事实口径、画幅和已确认版本。视觉精修不等于重写稿件或更换音色；用户明确指出“没有钩子／重做开头”时，可在开头范围内改稿、重配音并检查正文衔接，保留原声线。
- 新做完整长片时，以用户时长为准；本流程的账号目标为 **10 分钟以上**，可规划约 10–12 分钟，**且按账号默认 1.2 倍语速（火山 speech_rate=20）实测**，见[素材、事实与声音](references/editorial-and-materials.md)。样片通常 20–30 秒；不拿样片时长当长片要求，也不靠重复画面或放慢语音凑时长。
- 本次认可样式为横屏 16:9。其他画幅按用户和当前工程适配，不因为旧技能默认 dock 而自动增加上下品牌带、章节和进度条。
- 用户已认可方向就继续制作。只有更换主要视觉语言时，优先做一段动态样片验证；一般视觉样片覆盖实拍、证据与MG，开场样片按钩子需要编排，不强塞三种形式；不要每次常规修改都重新索要审批。

## 按阶段推进

新选题、完整长片或续作先读 [长片制作流程](references/long-form-workflow.md) 与 [管线手册](references/pipeline-playbook.md)。恢复当前选题、确认稿、音轨、素材、成片和发布包的版本；“继续”接着未完成项做，不重新选题或重做已确认内容。

- 只要求选题：交付有事实入口、素材可得性和传播钩子的候选，每个候选标注核心问题类型（见[叙事模式](references/narrative-modes.md)）和当下热点关联，热点题排前；不自动制作整片。
- 完整制作：选题与事实 → 长稿与钩子 → 素材覆盖 → 配音字幕与剪辑 → CTA → 检查与交付；已有确认环节直接复用。
- 只改视觉、CTA或发布材料：只做对应部分。发布包需求读 [AI封面与发布文案](references/covers-and-publishing.md)；“完整交付”默认包含成片、字幕、来源与检查说明、两种AI封面和适配文案。
- 不用普通确认点中断已经授权的制作；缺少影响事实、范围或执行的必要信息才提问。

## 项目结构

一期一个工程目录（`projects/<date>-<slug>/`：work/research、work/production、work/covers、outputs）加一个知识库目录（`knowledge/<date> <题名>/材料/`）。正文、来源、文案、封面、检查只在知识库维护，工程 outputs 用软链接；改镜头表后清空裁切目录重切；旧版本不删。完整树与版本规则见 [项目文件夹结构](references/project-layout.md)。

## 开场先建立观看理由

写稿前先读 [叙事模式与口播去套路](references/narrative-modes.md)：先定本期核心问题类型（账目、代价、规则、过程、对照、身份），连续两期不重复，开场句式黑名单不再使用。前约5秒就用具体冲突、反差或观众处境提出值得看下去的问题；不先寒暄、铺设购买情境或解释研究步骤。价格反差只是众多钩子中的一种，不是默认。钩子必须由正文中的事实支撑，不能为了吸引人暗示未经证实的供应关系、利润或违法。

开场以真实制作、拆盒、交易或事件动作推进，不用标题页、并排价格卡、大段证据截图起手。数字和短花字跟着动作出现，主体保持可见；静图加缩放、给卡片换动态背景，都不自动解决PPT感。Remotion是合成工具，不是必须采用卡片演示的视觉风格。具体编排与本次反例见[长片制作流程](references/long-form-workflow.md#开场回归酒店月饼)。

## 品牌先行

制作前读 [品牌与视觉](references/brand-and-visual.md)，核对当前账号 `brand` 配置，并查看真实 Logo。包内示例识别是 **SignPainter 手写签名＋星芒＋底划、强调色 #10C46F**；普通粗体账号名不能替代签名字标。

- 右上角放品牌字标，保持安静；没有左上章节、页码式标题或常驻进度条。
- **封面字标固定**：不让生图模型画签名，裁比例后用 `assets/brand-stamp.py` 合成，右上角、宽 = 图宽 22%、右距 4%、上距 3%，3:4 与 4:3 同规则，与成片右上角字标同几何。规则与验收见 [AI封面与发布文案](references/covers-and-publishing.md#字标固定合成2026-09-14-起)。
- 采用已认可的混合层次：真实素材保留颜色；信息层可用中性浅灰、柔和光影、灰绿与信号绿。不要把整片变成暖白杂志，也不要把整片压暗调蓝。
- 字体、色调或 Logo 的“升级”先对齐现有资产，再做细节；不要重新设计品牌。

## 画面与质感

视觉对标或精修先读 [视觉升级 v2](references/visual-collage-v2.md)，查看认可成片和拼板。核心为 **真实材质＋前后景分离＋统一拼贴处理**：主体敢于放大和局部出画，背景交代环境，白描边与轻投影分离层次，少量纹理统一素材。连续动作与参数以实际工程为准，不能仅凭抽帧猜测。

真实品牌或商品优先使用官方图、实物照、原视频帧的真实抠图；生成得像真物不等于真实商品。长片中实拍与相关动态影像承担主要叙事，静图平移、粒子和文字运动不计作实拍。先完成逐段素材覆盖，再安排图解。

蛋糕、暗网格、纸条只是案例表达；按新主题选择真实物件与镜头组合，不把所有视频固定成三页模板。证据保持可读，MG 保留机制解释，沿用现有品牌和音轨。

## 素材与调查

读 [素材、事实与声音](references/editorial-and-materials.md)。先从叙事提取主体、事件、订单、证照、原文和机制，再找素材：**主体真容／原报道／原始证据优先，Pexels 只补少量确有用途的环境过桥**。

保留来源台账、使用区间与素材原始分辨率。画面与当前句子对应；片名叫 screen 或 order 不代表内容匹配，绑定前必须查看。证据原件不能用 AI 仿造。

## 动画与阅读时间

读 [制作与验收](references/production-and-qa.md)。在已认可素材编排上精修，不把 MG 删除后只剩背景加字。

- MG 用于资金分配、关系、竞价等真正需要解释的信息。优先对象延续、比例拆分、路径绘制、轻微位移；所有数值和连接要有依据。
- 短花字完整稳定停留通常至少 2.5–3 秒；短句约 4 秒起，按字数调整。
- 证据通常安排 8–9 秒，确保入场和强调完成后仍有约 5 秒阅读；简单裁切证据可缩短，但不能只完成动画就退场。
- 数字逐项出现后保持；最终等式至少留约 3 秒。进入／退出时间不计入阅读时间。
- 普通素材可约 3–7 秒一切，随句义安排。快速装饰镜头不承载新文字。无需统一慢转场，优先在读完后直接切镜或按动作衔接。
- 字幕随实际语音整句稳定显示，不逐字跳动，不附句内进度线；不能强行给每条同步字幕套 3 秒规则。

## 制作与交付

使用 Remotion 帧动画，音轨由 FFmpeg 合成，**成片必须混入闪避配乐**（配方见 [管线手册](references/pipeline-playbook.md)）。字幕时间戳直接取火山 TTS 返回的逐字 `words`（2.0 音色须在 `audio_params` 传 `enable_subtitle: true`，`scripts/tts.mjs` 已默认打开），用 `scripts/subtitles-volc.py` 对齐；只有缺 words 的旧音频才回退 whisper。已有工程优先局部修改；先关键帧核对 Logo、字体、文字、素材，再整片渲染。依赖与路径查实际环境，不靠固定 localhost 端口判断当前项目。

完整成片片尾默认有简短点赞、收藏、关注CTA；结合本期价值，沿用已确认音色，重新核对新增字幕和总时长。

按本轮范围交付文件和实际检查结果；发布包中的封面默认为独立AI生图的3:4与4:3，不从视频画幅推导；字标由 `assets/brand-stamp.py` 后期固定合成，不让模型画。文案与封面版本须一致。样片不自动扩展成整片，制作不包含公开发布。

## 可复用资源

- 公共工序 `video-common`（同级的 `../video-common/`）：事实核查与来源台账、AI 封面比例验收、平台文案机制、成片机器验收与交付边界、合规自查。本 skill 只保留本账号特有的品牌、素材、叙事与阅读时间约定。
- [长片制作流程](references/long-form-workflow.md)：选题热点栏、点名品牌的出处与申诉材料、时长、开头、素材覆盖、动态统计与CTA。
- [叙事模式与口播去套路](references/narrative-modes.md)：六类核心问题、轮换规则、开场黑名单、写稿自检。
- [项目文件夹结构](references/project-layout.md)：工程与知识库两套目录的完整树、各文件用途、版本规则。
- [长片制作管线手册](references/pipeline-playbook.md)：热榜抓取、TTS/ASR 环境、证据裁图、竖屏内嵌、裁切缓存坑、配乐混音、封面与发布包的实际命令与路径。新项目从这里复制上一期工程。
- [AI封面与发布文案](references/covers-and-publishing.md)：3:4和4:3生图、标题、平台文案与打包。
- [视觉升级 v2](references/visual-collage-v2.md)：已认可的30秒质感样例、拼板、合成做法、最小工程与复现命令。
- [旧品牌对齐样片](references/approved-example.md)：早期 30 秒 MP4、拼板及机制解释参考。
- `assets/BrandStamp.jsx`：可复用 Remotion/React 签名字标组件；品牌值由当前账号配置传入。
- `assets/brand-stamp.py`：封面字标固定合成（右上角、22% 宽，与视频字标同几何）；生图不再画签名。
- `assets/publishing-reference/八平台发布文案-模板.md` + `assets/check-publish-copy.py`：发布文案固定模板与校验，平台顺序、字段、章节、置顶评论都固定；文案写完必须校验通过。
- `assets/finalize-outputs.py`：收尾固定生成 `outputs/<题名>-完整交付v<N>/`（成片/字幕/使用区间实体拷贝，文档与发布包软链到知识库），每期必须用它，不手工建 outputs。
- `scripts/subtitles-volc.py`：字幕对齐脚本，优先用火山逐字时间戳，缺失回退 whisper；复制到工程 `work/production/` 使用。
- `assets/reference-project/`：仅作已认可案例参考，不能把案例正文、日期、金额当通用默认。
- 样片压缩版 `assets/sample-preview.mp4`；最小 Remotion 参考工程在 `template/remotion/`。

原 `/shipai-changpian` 仍用于主生产管线、逐字稿保护与素材审计；需要该管线时按品牌参考中的路径读取相关部分。本技能独立保留本次风格与阅读约定，原技能的旧纸张、步进条、8–10 分钟或 dock 默认不覆盖用户当前要求。
